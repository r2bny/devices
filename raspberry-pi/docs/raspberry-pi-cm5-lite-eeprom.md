# Настройка EEPROM для Raspberry Pi CM5 Lite на Debian GNU/Linux

**Инструкция только для Compute Module 5 Lite** (версия без eMMC).
## 1. Проверка прошивки
Проверьте текущую версию EEPROM:
```bash
vcgencmd version
```
Прошивка должна быть **новее 2025-01-06**. Если она устарела — обновите:
```bash
sudo rpi-eeprom-update
```
## 2. Редактирование EEPROM
Откройте конфигурационный файл EEPROM:
```bash
sudo rpi-eeprom-config -e
```
**Обязательно** сделайте резервную копию текущей конфигурации перед изменениями!
### Рекомендуемая конфигурация:

```ini
[all]
BOOT_UART=1

# Выключать выходы PMIC при HALT
POWER_OFF_ON_HALT=1

# Порядок загрузки: SD → NVMe → USB → Network
BOOT_ORDER=0xf461

# Повторять попытки загрузки с SD-карты
SD_BOOT_MAX_RETRIES=2

# Замедлить SDR-режим SD-карты (решает проблемы с загрузкой)
SD_QUIRKS=1
```

## 3. Применение изменений

Сохраните файл и перезагрузите модуль:

```bash
sudo reboot
```

## Дополнительно

- Если SD-карта не загружается, используйте проверенный рабочий образ для первоначальной прошивки EEPROM.
- После применения конфигурации модуль должен корректно определять NVMe-накопитель через адаптерную плату.
